# Nova Display Calibration 0.4.0

Measured SDR calibration profiles for the Retroid Pocket Nova: sRGB gamut, D65 white point, Gamma 2.2 or sRGB tone response, and an approximately 225 cd/m² reference at brightness 173/255.

The system loads the profile after a full restart and keeps it through sleep. The app requires no background service and declares no Android permissions. Privileged installation uses the OEM service already present in the supported firmware.

This first public version packages calibration deltas rather than manufacturer configuration files. The reconstructed outputs match the measured profiles byte for byte. The repository includes 921 RGB/XYZ readings, camera examples, implementation details, and validation records.

Project by **pippopapera**, developed with substantial assistance from **OpenAI Codex** in code, measurement analysis, testing, and documentation. [Contributors and AI disclosure](https://github.com/pippopapera/nova-display-calibration/blob/v0.4.0/CONTRIBUTORS.md).

**Supported test configuration:** Retroid Pocket Nova, firmware `RPN_V1.0.0.436_20260722_083524_user`. One measured unit; generic OLED CCSS, so absolute colorimetry is provisional. Other firmware/models are unsupported. The test unit already had an unlocked bootloader.

**Before uninstalling or updating firmware:** select **Restore original** and restart. Keep system saturation at 100%. OdinTools need not remain installed.

See the [README](https://github.com/pippopapera/nova-display-calibration#readme) for installation, measurements, compatibility, and recovery. Photos are illustrative; camera processing and viewing conditions affect their appearance.

## Download and verification

Download **Nova-Display-Calibration-0.4.0.apk** below. Android may ask you to allow installation from your browser or file manager. The app itself requests no Android permissions.

- Package: `local.nova.diagnostic`; version `0.4.0` (code `4`).
- APK size: **74,903 bytes**.
- APK SHA-256: `7ee25693246df145bd3c892ea67a61bc98beaf5a3cdbd5fb09035fa5dbf1a371`.
- Signing certificate SHA-256: `f6c76258cf877435f5f1e453569ec131f92f6c284f7fa99783360a7aa10cca34`.
- Dedicated RSA-4096 signing key; APK signature schemes v2 and v3 verified. The private key is not distributed.

`SHA256SUMS.txt` contains the APK checksum. On Windows, run `Get-FileHash .\Nova-Display-Calibration-0.4.0.apk -Algorithm SHA256`; on Linux, run `sha256sum -c SHA256SUMS.txt` in the download directory.

The signed APK was freshly installed on the supported Nova and tested with sRGB, original restore, Gamma 2.2, full restarts, and force-stop plus sleep/wake. Hardware readback confirmed the expected correction. [Release validation](https://github.com/pippopapera/nova-display-calibration/blob/v0.4.0/docs/verification/release-signature-validation.json).

**Moving from a private laboratory build:** its signing key differs. Restore the original profile, restart, then uninstall that build before installing this release. Future official updates should retain this release signing identity.
