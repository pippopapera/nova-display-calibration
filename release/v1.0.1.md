# Nova Display Calibration 1.0.1

Fixes the saturation setup that could keep showing “Set OdinTools saturation to 100%” even after the slider had been reset.

Select Gamma 2.2 or sRGB. If prompted, choose **Reset and apply**, then restart when requested. The app resets both Android's current and saved saturation to 100% and checks the display before saving the calibration. OdinTools is not required. **Cancel** makes no changes.

The previous check read only the saved system property, which can differ from the current setting changed by OdinTools. Android's startup handling also requires the exact saved value `1.0`; simply accepting an empty or differently formatted value can bring back boosted saturation at reboot. [Technical explanation and troubleshooting](https://github.com/pippopapera/nova-display-calibration/blob/main/docs/SATURATION.md).

Other color filters are not disabled. If a filter remains active, installation stops with a specific message. **Restore original** removes the panel calibration and restores saved brightness; the explicit saturation reset remains at 100%.

The Gamma 2.2 and sRGB profiles are unchanged. Firmware and ownership safeguards remain in place. No new permissions, background services, boot receivers or dependencies were added. Logs now distinguish the saved saturation from the internal display's active color transform.

Install this APK over 1.0.0; the signing key is unchanged. No uninstall is needed.

Validation: 21 decoder checks, 10 installer test methods, and physical Nova tests covering cancellation, reset, Gamma 2.2/sRGB/restore with full reboots, hardware readback, and sleep/wake with the app stopped. These are software and hardware-state checks; the measured profile bytes are unchanged and no new optical measurements are claimed. [Verification record](https://github.com/pippopapera/nova-display-calibration/blob/main/docs/verification/release-1.0.1-validation.json).
