# Nova Display Calibration 1.0.2

Fixes [issue #3](https://github.com/pippopapera/nova-display-calibration/issues/3): version 1.0.1 could show **Could not verify the display color settings. Profile not saved.** even with saturation already at 100%. Operation details included `printf: Argument list too long`.

This was an app bug, not a missed setup step. Android's display diagnostic report could exceed the size accepted by a command argument. The app now reads that report as a stream and retains only the internal display's color matrix. Incomplete, failed, ambiguous or malformed reports are still rejected.

## Updating

1. Download **Nova-Display-Calibration-1.0.2.apk** and install it over your existing version. No uninstall is needed; the signing key is unchanged.
2. Open Nova Calibration and select **Gamma 2.2** or **sRGB**.
3. If prompted, choose **Reset and apply**. The app handles the required saturation reset; you do not need to reinstall OdinTools or reset it manually.
4. Restart when requested.

The calibration curves, firmware safeguards, permissions and background behavior are unchanged. No new optical measurements were needed or performed.

Validation: 21 decoder checks, 12 installer test methods, and nine parser cases under the physical Nova's Android shell, including reproduction of the old error with a report larger than 2 MB. The signed APK was checked through reset/cancel, profile application, full reboots, original-profile restore, hardware readback and sleep/wake.
